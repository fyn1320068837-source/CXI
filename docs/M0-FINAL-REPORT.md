---

### ✅ M0.2 - PF 按组阻断验证

**状态**: 通过  
**验证方法**: pfctl 语法验证

**测试规则**:
```pf
block return out quick proto tcp from any to !127.0.0.0/8 group cimgrp
block return out quick proto udp from any to !127.0.0.0/8 group cimgrp
```

**关键发现**:
- pfctl 识别 `group` 关键字
- 报错为 "unknown group"（组未创建），而非语法错误
- 证明 macOS PF 原生支持按组过滤

**技术可行性**: ✅ 完全可行

---
