安装方式

1
克隆仓库并安装
git clone https://github.com/fyn1320068837-source/CXI.git cd CXI ./install.sh
2
打开控制台
open http://localhost:8080
3
配置 SOCKS5 代理
在控制台中点击「配置代理」，填入住宅代理信息。密码自动保存到 macOS Keychain。
4
安装防火墙规则（推荐）
sudo cim install-firewall
5
卸载
./uninstall.sh
