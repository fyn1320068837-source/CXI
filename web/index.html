安装步骤
1
克隆仓库并安装
git clone https://github.com/fyn1320068837-source/CXI.git cd CXI ./install.sh
安装脚本将自动构建二进制、下载 sing-box、注册 launchd 服务并启动守护进程。
2
配置 SOCKS5 代理
nano ~/.cim/config.toml
填入住宅代理的 host / port / 用户名，密码通过 macOS Keychain 单独保存，不写入配置文件。修改后重启服务：
launchctl unload ~/Library/LaunchAgents/com.cim.daemon.plist launchctl load ~/Library/LaunchAgents/com.cim.daemon.plist
3
安装 PF 防火墙兜底规则（推荐）
sudo cim install-firewall
提供内核级 fail-closed 保护。代理故障时自动阻断所有实例的公网直连，防止意外泄漏。
4
远程访问（SSH 端口转发）
ssh -L 8080:localhost:8080 youzhisan@100.95.96.47
随后在本机打开 http://localhost:8080 即可访问远程 Mac Studio 的控制台。
5
卸载
./uninstall.sh
完整移除守护进程、launchd 服务、PF 规则和二进制文件，可选择是否保留 ~/.cim/ 数据。
